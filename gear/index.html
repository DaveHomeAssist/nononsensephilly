    Local simulation / no device connection

    Know the plate before you patch it.

    Socket roles are the recorded lettering on the Bauder plate, not measurements. Nothing here asserts a pinout, polarity or which sockets reach the driver.

    Simulated S-181 state

    

    Rear sockets
    Each button only reads back the recorded role of that socket.
    

    Load check
    Each S-181 is 8 Ω nominal with an 8.0 Ω minimum. Cabinets daisy-chained on one amplifier channel sit in parallel.
    The amplifier's own minimum-load rating is not part of this model; check it on the amplifier before patching.
