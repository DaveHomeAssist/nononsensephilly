# Flyer Kit Studio brief

The existing Flyer Kit explains the workflow. Nick can now use the same page to turn a short brief into a generator-ready prompt, reuse an event, and write a targeted edit for an existing flyer.

- Flow: choose a flyer treatment and format, enter visual direction, build and copy a prompt. For revisions, describe the requested changes and what to keep, then attach the original artwork in the image generator. Keep approved show copy in a separate placement block.
- Data: save named briefs to versioned browser storage only when requested. Reopen a brief to update it or start a new one. An explicit save is the persistence boundary. No account, API, asset upload, or change to canonical events.
- Design: use published flyer art as reference, retain the guide and downloadable Codex skill, and support light and dark themes. The document stays locked to the viewport with bounded work panels and mobile bottom navigation.
- Release: keep the existing direct URL and robots directive. Leave the route out of navigation and the sitemap. The private portal remains a separate decision.
- Acceptance: verify the generate and revise paths, copy fallback, save and reopen across reload, keyboard navigation, and viewport bounds at 1440 × 900 and 375 × 812.
