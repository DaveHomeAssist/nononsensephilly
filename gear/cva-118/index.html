    Connections and controls
    Each button only reads back what the manufacturer document says that connector or control does.
    

    Two subs, one setting
    Feed the first sub, set its Low Pass and make it Master. Link Out to the second sub set to Slave so both roll off at the same point. Tops come off Thru with the High Pass set to match.
    The quick reference says leave High Pass on Bypass if unsure.
