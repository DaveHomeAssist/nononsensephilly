    Local simulation / no device connection

    Simulated CDJ-3000 state

    

    Connections and controls
    Each button only reads back what the manufacturer document says that connector or control does.
    

    Link two players
    One LAN cable from each CDJ-3000 to the mixer's LINK ports (or a switch) lets both read one USB stick or SD card and sync. Audio still leaves each player on its own RCA or digital pair.
    The DJM-A9 has the LINK hub; this model does not simulate the network.
